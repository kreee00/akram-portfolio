Organisation logos live here (png, jpg, webp, svg). Any size; the build shrinks them.

Get them automatically: set a domain for each org in src/data/orgs.js and run
  npm run logos

Or add your own: name the file after the organisation, e.g.
"Universiti Teknologi PETRONAS" -> universiti-teknologi-petronas.png,
or set logo: "file-name.png" on the org in src/data/orgs.js.

Orgs without a logo show their initials.
