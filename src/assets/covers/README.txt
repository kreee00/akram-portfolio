Book covers live here (jpg, png, webp, avif). Any size; the build shrinks them.

Get them automatically: add an isbn to each book in src/data/books.js and run
  npm run covers

Or add your own: name the file after the book title, e.g. "Atomic Habits" -> atomic-habits.jpg,
or set cover: "file-name.jpg" on the book in src/data/books.js.
